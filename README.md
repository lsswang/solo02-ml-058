# Bond evidence and reaction quantities

Python 3.11, NumPy and SciPy. Run python demo.py in this folder.
graph_model.independent scores independent bond orders 0/1/2.
reactions.net_plan finds a minimum-cost integer net-stoichiometric plan.
reactions.fire replays one reaction by checking consumption before simultaneous production.
Species order indexes every stock/consume/produce vector.
The fixtures use synthetic indexed structures and abstract reactions.
No real chemical synthesis or physical validity is claimed.
